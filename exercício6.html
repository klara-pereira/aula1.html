Tag: Header

A tag Header serve para criar o cabeçalho de uma página web ou de uma seção específica

Tag: Main

A tag Main indica o conteúdo principal e único de uma página ou aplicativo

Tag: Nav

A tag Nav serve para criar uma seção de uma página dedicada a links de navegação

Tag: Section

A Tag Section agrupar conteúdos relacionados que compartilham um mesmo tema

Tag: Article

A tag Article serve para marcar um conteúdo que faz sentido por si só e é independente

Tag: Aside

A tag Aside serve para marcar conteúdos que têm uma relação indireta ou secundária com o texto principal da página

Tag: Figure

A tag Figure agrupar um conteúdo independente como uma foto, ilustração, diagrama, vídeo ou trecho de código junto com a sua legenda opcional, formando uma única unidade semântica

Tag: Footer

A tag Footer define o rodapé de uma página ou de uma seção específica
